# NLP Lab 4: Classification and Evaluation

This repository contains the implementation of NLP Lab 4, focusing on text classification and model evaluation using sentiment analysis.

## Lab Tasks

The lab includes:
- Text preprocessing
- Sentiment classification
- Train and test data splitting
- TF-IDF feature extraction
- Naive Bayes classification
- Model evaluation using accuracy and classification report
- Confusion matrix analysis

## Dataset

The tasks use the Amazon Unlocked Mobile Reviews dataset to classify customer reviews into three sentiment categories:
- Positive
- Neutral
- Negative

## Tools and Libraries

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes
